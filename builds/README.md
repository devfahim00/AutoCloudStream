# builds/

Compiled `.cs3` plugin files and `plugins.json` land here automatically
whenever the **Generate Provider** or **Build All Plugins** workflows run.

Install in CloudStream: Settings → Extensions → Add repository, then use

```
https://raw.githubusercontent.com/devfahim00/AutoCloudStream/main/builds/plugins.json
```

or download a single `.cs3` from this folder and sideload it manually.
